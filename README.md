# 👑 مساعد يوهو VIP
## النسخة 1.0 - لهواتف شاومي أندرويد

### الميزات:
- 🖼️ إطارات ملكية للصور + لمعان + اسم
- 🔘 أداة عائمة فوق يوهو تفتح المحرر
- ⚙️ لوحة إعدادات عربية سهلة
- 💾 حفظ الصور المزينة ورفعها لـ يوهو
- 🚫 بدون دفع - بدون اختراق - 100% آمن

### التشغيل:
1. افتح المشروع في Android Studio
2. شغل التطبيق على جهاز شاومي
3. فعّل "الظهور فوق التطبيقات" من إعدادات النظام
4. ستظهر أيقونة ذهبية 👑 فوق التطبيقات
5. اضغط عليها لفتح مساعد يوهو VIP

### الملفات الرئيسية:
- `MainActivity.kt` - الشاشة الرئيسية
- `FloatingService.kt` - الأداة العائمة
- `FrameEditor.kt` - محرر الإطارات والديكورات
- `activity_main.xml` - واجهة المستخدم الرئيسية
- `layout_floating.xml` - الأداة العائمة

### الملاحظات:
- لا يمكن تعديل واجهة يوهو من الداخل (ضد قوانينهم)
- الحل: نزين الصور خارجياً ثم نرفعها
- اصدقاؤك سيشوفون الصور المزينة ✨
