# 👑 مساعد يوهو VIP - Yoho VIP Assistant

تطبيق أندرويد متخصص لتزيين الصور بإطارات ذهبية وفضية فاخرة وإضافة اسمك عليها!

## ✨ الميزات الكاملة

- ✅ **إطار ذهبي ملكي** - إطار ذهبي مع لمعان عالي
- ✅ **إطار فضي فاخر** - إطار فضي عصري واحترافي
- ✅ **إضافة الأسماء** - كتابة اسمك بخط جريء على الصورة
- ✅ **أداة عائمة** - زر 👑 يظهر فوق جميع التطبيقات
- ✅ **التقاط صور مباشرة** - من الكاميرا أو المعرض
- ✅ **حفظ آمن** - الصور تُحفظ في هاتفك فقط
- ✅ **واجهة عربية** - سهلة الاستخدام
- ✅ **آمن 100%** - بدون بيانات شخصية

## 📥 التحميل والتثبيت

### ⬇️ الطريقة 1: تحميل APK جاهز (الأسرع)
```
1. اذهب إلى: https://github.com/amynzby06-hue/yoho-vip-assistant/releases
2. حمّل آخر نسخة APK
3. انقل الملف إلى هاتفك
4. اضغط على الملف وثبتها
5. فعّل الأذونات المطلوبة
```

### 🛠️ الطريقة 2: البناء من Android Studio
```bash
# 1. Clone المشروع
git clone https://github.com/amynzby06-hue/yoho-vip-assistant.git
cd yoho-vip-assistant

# 2. افتح في Android Studio
# File → Open → اختر المجلد

# 3. اضغط Run أو Shift + F10
```

## 🚀 طريقة الاستخدام

| الخطوة | الإجراء |
|------|--------|
| 1️⃣ | افتح التطبيق |
| 2️⃣ | اضغط **"🖼️ اختر صورة"** |
| 3️⃣ | اختر من المعرض أو التقط صورة جديدة |
| 4️⃣ | أدخل اسمك (اختياري) |
| 5️⃣ | اضغط **"✨ إطار ذهبي"** أو **"💎 إطار فضي"** |
| 6️⃣ | اضغط **"💾 احفظ الصورة"** |
| 7️⃣ | تم! الصورة محفوظة في المعرض |

## ⚙️ الإعدادات المطلوبة

### 1️⃣ تفعيل إذن الظهور فوق التطبيقات

**على معظم هواتف Android:**
```
Settings → Apps → Special app access → Display over other apps
→ ابحث عن "مساعد يوهو VIP"
→ فعّله ✅
```

**على Xiaomi:**
```
Settings → Permissions → Display over other apps
→ "مساعد يوهو VIP" ✅
```

### 2️⃣ الأذونات الأخرى
- ✅ الوصول للمعرض (للصور)
- ✅ الوصول للكاميرا (لالتقاط صور)
- ✅ الكتابة على التخزين (لحفظ الصور)
